# Initial Reference Model v3 说明

配套图：`initial-reference-model-v2-english.mmd` 与 `initial-reference-model-v2-chinese-gen-z-zh.mmd`。

## 这张 Reference Model 说明什么

它不是三个原型将带来什么效果的图。它只描述本研究要理解的**当前或可调查情境**：成年中国 Gen Z 参与者如何处在超级应用、生成式 AI 对话与新兴 AI agent 同时存在的数字环境中；这些系统怎样可能组织他们的生活、认识与行动；以及参与者是否察觉到这种塑造。

三个颜色分支不是一条所有人都会经历的技术进化史：

| 分支 | 研究的具体问题 | 当前证据边界 |
|---|---|---|
| 橙色：超级应用 | 跨服务整合、默认设置、商业引导、数据不透明与退出难度，怎样组织日常流程和社会表达？ | 超级应用是现实日常情境；具体关系仍要通过走查和参与者叙述检验。 |
| 蓝色：生成式 AI 对话 | AI 承担推理、贡献是否可见、是否有核验机会，怎样参与知识形成？ | 有已有研究，但实际使用程度和效果在参与者间不同。 |
| 紫色：AI agent | 当系统按规则代表人行动时，委托范围、例外、确认与撤回怎样影响真实生活情境？ | 这是新兴且部分推测性的情境，不能写成每个人已经拥有的日常经验。 |

## 唯一 Key Factor

> **察觉数字系统如何塑造生活、认识与行动方式**

它不是“用户有没有设置权限”，也不是给人打 agency 分数。它问的是：

> 用户能否意识到，自己并非只是使用一个中性工具；该系统也在参与塑造自己的日常流程、理解过程与现实行动？

例如：

- “我以为自己只是习惯用某个 app，但群聊、支付和推荐已经把我的日常安排组织成一种默认流程。”
- “我以为 AI 只是帮我破案，但我发现自己跳过了哪些推理并不清楚。”
- “我以为我已给 agent 设定规则，但具体关系和例外无法被预先写完。”

## 图中 Success Factors 为什么出现在 Reference Model

DRM 要求在 Reference Model 中先标出研究最终关心的因素，再转入 Impact Model。它们不是已经出现的研究效果：

| 因素 | 意思 |
|---|---|
| **G5 Key Factor** | 是否察觉系统的塑造作用。 |
| **G6 Measurable Success Factor** | 在研究中可观察：能否把具体系统安排与生活后果联系起来。 |
| **G7 Success Factor** | 更高层目标：能否说清希望系统怎样参与、又不希望它怎样参与。 |

G5 → G6 → G7 是目前的设计假设，因此标 `[A]`；不是已经被本研究证明的因果链。

## 箭头和来源怎样读

| 标签 | 意思 |
|---|---|
| `[R01]` 等 | 相应文献在其原研究情境中提供了直接或相近依据。 |
| `[A;R01]` | 本研究基于文献提出的迁移性假设；它不等于文献已经证明中国 Gen Z 的这条关系。 |
| `[A]` | 研究者或设计假设。 |
| `[?]` | 关系或方向仍未知，正是未来走查、原型和访谈要调查的内容。 |

Reference Model 中三条通向 G5 的虚线标 `[?]`，是有意保留的自我审查：平台更深地组织生活、AI 更深地参与知识、或 agent 更深地代表行动，是否会提高、降低或以其他方式影响参与者的察觉，不能在研究开始前替参与者回答。
