# 书页式说明书原型 · 0.2

## 打开

双击 [启动书页.command](book/启动书页.command)，会启动只监听本机的服务并打开浏览器。也可以在 `book` 目录运行 `node server.mjs`，打开它打印的 Local 地址。

先出现的是明确标注的虚构示例。可以翻页、打开来源、改写、保留或删除一页。示例里的操作只留在本次网页预览，不会当作个人资料保存。点击底部“试一次书页更新”，可看到一条标明为虚构演示的新书页出现。

## 和 Codex 一边聊一边写

1. 点击“开始我的说明书”，填写化名和眼前的问题。阅读本机保存说明后，按本人意愿创建。
2. 复制页面给出的启动文字，发送到 Codex 新聊天。它包含本人的书页编号和同步协议。
3. 保留书页窗口。聊天中形成值得留下的一小段内容后，整理 skill 使用本地工具更新；页面约每 1.4 秒检测一次记录变化并显示。
4. 在书页里改写或认可的条目受到保护，后续 AI 更新不能直接覆盖。可以从某页复制继续聊的说明，交给 Codex。

这条连接使用当前 Codex 对话的模型，没有另外调用模型 API。书页本身不读取聊天历史，也不会自行导入这次论文聊天的个人经历。

## 书页中的比喻

Memory 是留在我身上的经历，Skill 是逐渐学会的做法，Loop 是常出现的做事方式，Tool 是可借助的工具与支持。页面另有“在乎的事”和“暂时开放的问题”，也容纳新的类别。一个具体经历可以连接到几种不同理解。

类别随着已有内容出现。没有填满所有章节的要求。AI 的新解释显示为待确认，参与者可以改写、认可、暂留或删除。当前版本的“本人认可”由页面上的明确操作设置；聊天中的口头认可可继续沿用，但不会由后台自动改成页面确认状态。这项交互选择需要继续试用。

## 保存、删除和导出

个人记录保存在 `book/data/sessions/`，与示例分开。服务只绑定 `127.0.0.1`，没有外网发布、账号系统或跨设备同步。这里的隔离依靠本地运行、独立编号、工具范围和对话指令，不构成安全沙箱。

删除一页，会移除它的书页、所保存的引文及对应关联；其他书页的文字仍保留，聊天历史不受影响。程序不另外保存旧版本。源文件中没有个人说明书内容。

“带走这份说明书”会导出可继续修改的 Markdown 文件。停止服务可运行 `node stop.mjs`；再次打开启动器，个人记录仍在本机。原来的个人说明书 URL 中带有编号，保留该地址即可再次打开。

## 当前实现范围

完成书页呈现、翻页和目录、来源展开、关联跳转、本人改写与确认、删除、导出，以及 Codex 通过本地工具写入后的页面更新。尚未加入网页内聊天、独立多用户登录或远程试用。

界面示例和程序检查均使用虚构材料。它们验证交互和数据流程，不提供真人自我探索效果的证据。
