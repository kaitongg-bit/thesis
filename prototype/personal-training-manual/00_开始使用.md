# 个人训练说明书：对话机制原型

对话机制版本：0.6（研究者试用）；日期：2026-11-04。

这一版在 Codex 聊天中运行。五个 skills 安装在当前用户的 `~/.codex/skills/`。它使用当前 Codex 会话的模型和用量，无需另建 API 应用。本轮制作集中于对话机制与记录方法。

新版从聊天开始。开场提供具体入口、说明将做出什么，并确认一次本机保存选择。有第一段足够具体的材料后，AI 自动创建含有首批内容的书页并打开；之后边聊边修改这份初稿。参与者无需先开网页、填编号或复制连接信息。[书页使用说明](06_书页原型_使用说明.md)介绍保存和接续方式。

## 在新聊天中开始

在新聊天里发送：

> 请使用 $personal-training-manual，开始新版书页式体验。先读完整的 SKILL.md、conversation-contract.md 和 session-flow.md。请把我当作第一次接触的参与者：引导我选择一个具体入口，说明本机保存并确认一次；有第一段有用材料后，自动生成初稿、打开我的书页，随后围绕它继续聊和更新。

如果新聊天暂未发现 skill，可以发送：

> 请读取并使用当前用户目录下 ~/.codex/skills/personal-training-manual/SKILL.md，先读其要求的两个开场参考文件，再按路由读取配套 skills，开始新版书页式体验。

新聊天应直接进入体验。它不会自动获得本论文聊天的个人经历，也无需预先阅读论文、文献综述或其他人的记录。

0.4 将“世界怎样训练了我”设为实际探索主线。主持者在一件事聊清后，主动提议回看过去或比较另一种生活场合，把相关经历连成有依据的 memory、skill、loop、tool 理解。参与者不需要先提出这些角度，也不必答完一套人生问卷。

0.5 进一步要求：换到过去的场合之后，仍要记住为什么回看它。每个问题都应帮助理解这个人的做法、处境或在乎的事情；新回答可以改变原来的理解。退出某条路的原因需要本人说明，时间、收入和机会等现实条件同样重要。

0.6 移除由作者经历改编的示例，补充连续建议之后如何回到共同探索，以及如何防止把推测的学习历史写成本人事实。用独立开发题、候选冻结后的保留题和隐去版本标签的审阅检查实际行为；目前不能据有限比较宣称整体体验优于旧版。评测规则见 [独立回归检查协议](evaluation/PROTOCOL.md)。

已有体验聊天不会自动重新加载修改后的文件。继续同一份记录时，可发送：“请重新读取 0.6 版总入口及其必读文件，从已有材料继续。保持当前探索目标，根据我的新回答修正理解；保留我已改过的书页，不用从头问。”

本机已安装并配置好书页工具。换电脑或重新安装时，在本原型目录运行 `node book/install-skills.mjs`，将五个 skills 及当前书页位置一起配置到自己的 Codex。该命令会更新五个同名 skills；若做过个人改动，请先备份。同一聊天创建的书会继续使用同一个编号。

## 可以直接说的话

- “我想从最近一次实习说起。”
- “这个问题太大了，帮我找个更容易讲的入口。”
- “先别追问，帮我整理目前说过的。”
- “这个解释不像我，改成……”
- “这些术语有点别扭，用普通中文。”
- “先留着这个矛盾，我现在也说不清。”
- “把刚才的内容做成一份聊天里的说明书。”
- “这一段不放进说明书。”
- “今天到这里。”

这些是自然语言入口，不要求参与者背命令。AI 应主动根据上下文选用相应机制。

## 五个 skills 的分工

| 名称 | 职责 |
| --- | --- |
| `$personal-training-manual` | 开始和继续体验；确认当前话题；协调各模块；控制节奏 |
| `$ptm-explore-experience` | 帮助回忆、展开事件、探索形成条件、比较经历 |
| `$ptm-work-and-values` | 区分会做与在乎；讨论现实条件、AI 与具体工作；发展可选的下一步 |
| `$ptm-repair-conversation` | 修正误解、调整问题与术语、处理停顿和结束、应对明显不适 |
| `$ptm-build-manual` | 分阶段整理、注明来源和确认状态、修改和保存说明书 |

用户通常只需调用总入口。它应按情境读取其他模块。Skill 是对模型的引导，实际表现仍需检查。

## 本轮材料

- [机制设计](01_机制设计.md)：目标、各模块的决定和具体提问方式。
- [文献依据与设计决策](02_文献依据与设计决策.md)：哪些来自文献，哪些是本项目提出的做法。
- [测试情境与验收](03_测试情境与验收.md)：用具体案例检查表现。
- [先导试用与研究记录](04_先导试用与研究记录.md)：怎样开展后续试用、收集有用的材料。
- [本轮检查记录](05_本轮检查记录.md)：实际做了哪些检查、发现和修改了什么。

研究者可以先自行体验并调试。模拟检查与研究者自用应如实标注；参与者研究需按学校要求开展并单独取得相关同意。个人说明书的保存和研究材料的使用分别确认。
