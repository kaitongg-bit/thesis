# 书页原型检查记录

## 0.3：引导、自动建书和持续修改

日期：2026-11-02。新增检查全部使用明确标记的合成参与者材料。没有导入真人聊天、简历或已有个人说明书。

### 多面了解地图的增补

新增总入口必读的选题参考 `understanding-map.md`，区分各个面的材料覆盖、当前解释、本人反馈和开放的替代解释。维度用于提出与当前问题相关的新角度；参与者不必全部回答。没有增加心理测评分数或网页置信度面板。

一次独立只读合成检查使用设计岗求职、独自做海报与合作做展览的材料，并明确排除家庭话题。回复区分了设计任务与合作条件，保留家庭边界，以已有材料形成聊天初稿；检查报告区分了具体情境、笼统自评与尚未涉及的面。该结果仅为一次模型执行观察。

在后续同一合成情境中，参与者明确停止展览细节并要求换角度。回复停止原问题，提出学习方式、自己的评价标准、职业期待三个新角度，并用已经提到的“满意的海报”连接到评价标准，未继续追问家庭或展览。这个观察支持选题指引在该情境下可被执行，仍不代表所有后续对话都稳定如此。

另修正保存选择的状态：开场只回答主题时仍是“待确认”，首次初稿出现后应补问保存选择；明确拒绝后不反复询问，明确同意后正常自动更新。此条根据实际使用中漏答保存问题的情况修订，不能由此前明确授权的合成检查替代验证。

### 实际执行

独立 agent 读取已安装的总入口与配套机制，接收一条包含本机保存授权、社团报名表经历和当下困惑的合成参与者消息。它实际调用工具创建一份新书：首次写入成功时已有 4 条内容，版本为 1；浏览器核实了首批内容。主代理随后在内置浏览器中打开相同书页，未要求复制会话编号。

主代理直接在网页改写经历页标题，页面显示“本人改写”，记录版本变为 2。独立 agent 收到新的合成参与者补充后，继续修改同一本书。首次提交遭遇 409 版本冲突，它重新读取版本 2，保留本人改写，再成功更新到版本 3，共 6 条内容。主代理在未手动刷新页面的情况下观察到新内容，并翻页检查新的积累与支持页。

已保存当前合成书页截图 `book/preview-v03.png`。本检查创建的是虚构工程检查记录，不是用户的个人说明书，也没有把它的本机数据文件提交到代码仓库。

### 观察后修订

首轮自动生成的正文包含“尚不能认定为稳定能力”等研究报告口吻。已修改写作指引：研究限制留在研究者材料，书页通过来源、待确认状态和具体开放问题表达不确定性。再次执行后，正文改为实际做过的事、可以继续使用的参照及本人在乎的内容。

另一次只读独立检查给出了首次开场及参与者说“不知道说什么”后的回应。开场包含产物、具体入口和一次本机保存选择；没有具体材料时不创建空书。检查后进一步明确，无入口时先用学习、工作或求职中的具体场景帮助回忆。

### 程序检查

`node --test tests/*.test.mjs` 共 9 项通过。除原有保护、来源、删除与版本检查外，新增首批内容原子创建，以及隔离临时目录中的“自动启动服务—创建—读取—更新同书—取得链接—不同书隔离—拒绝过期写入”检查。安装后的 helper 和所修改 skills 通过语法或结构检查。

### 证据范围

以上检验了工具链、一次合成体验的实际调用和一次带网页改写的继续整理。尚未证明任意新聊天都能稳定保持引导质量，也未验证真人自我理解、价值感或长期使用效果。浏览器打开失败时提供已保存书页链接；保存失败时在聊天中交付初稿并明确说明。

## 0.2：原有书页与同步检查

日期：2026-11-01。检查使用虚构示例与单独的功能测试说明书，没有导入论文聊天或真人参与者的个人记录。

## 程序检查

运行 `node --test tests/store.test.mjs`，7 项通过：本人改写页的覆盖保护、旧版本写入冲突、删除后的引文与关联移除、AI 不能直接设置本人认可状态、无效来源拒绝、并发写入与完整 JSON 保存、会话编号不能越过存储目录。另检查前端 JavaScript 语法。

这些是程序行为测试，不评价心理效果或长期使用价值。

## 实际浏览器操作

在 Codex 内置浏览器中检查封面与普通书页，并实际完成：翻页、打开改写窗口、修改示例正文、看到“本人改写”状态、新建一份标明为虚构功能检查的说明书、取得其聊天连接说明。

通过 `bookctl.mjs` 读取该说明书的初始版本，再通过交互式标准输入写入一条合成经历和一条 AI 暂时解释。工具返回成功后，浏览器在没有手动刷新的情况下显示了两页新内容。随后点击“这句话像我”，页面显示“本人认可”。

这验证了“聊天工具调用—本地记录—书页检测更新”的完整连接。尚未以真人的长时对话测试何时更新最自然、更新是否打断阅读，以及页面确认会带来多少额外负担。

## 根据显示检查作出的修改

第一轮封面在普通笔记本窗口中使翻页按钮落到屏幕下方。已调整桌面高度与短屏字号，随后截图确认封面、翻页和底部操作可同时看到。正文较长或来源展开时，单页可以滚动。

## 实现边界

书页通过轮询读取记录，通常在下一次约 1.4 秒的检测后显示已成功写入的内容。它不会逐字读取 Codex 的实时聊天，也不会自动读取过去的对话。

当前在本机运行，保存到独立会话文件。没有外网部署、账号隔离或多人并发研究的完整安排。聊天中的口头认可与页面确认之间的对应、用户删改后的继续探索，以及更长说明书的组织，仍需要后续试用。
